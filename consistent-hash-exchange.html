Consistent Hashing (User Affinity)

使用 rabbitmq-consistent-hash-exchange 外掛，將相同 User 的訊息固定路由到同一個 Queue，從物理上避免多 Consumer 競爭導致的亂序問題。

Hash(Routing Key)
原理： Exchange 會對 Routing Key (這裡使用 UserID) 取 Hash，映射到環上的點，然後路由到對應的 Queue。確保相同 User 永遠進同一個 Queue。
